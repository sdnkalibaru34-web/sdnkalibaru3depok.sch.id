# Website Resmi SDN Kalibaru 3 Depok

Website resmi SDN Kalibaru 3 Depok.

## Struktur Proyek

- `index.html` — beranda
- `halaman/` — halaman utama website
- `data/` — data konten yang mudah diperbarui
- `konten/` — dokumen, pengumuman, agenda, prestasi, dan galeri
- `assets/css/` — stylesheet
- `assets/js/` — JavaScript
- `assets/images/` — gambar website
- `assets/icons/` — ikon
