# Folder Gambar Website

Gunakan folder ini untuk aset gambar yang dipakai langsung oleh halaman website.

## Nama file hero

- `hero-sekolah.jpg` — hero profil
- `hero-informasi.jpg` — hero informasi
- `hero-ekstrakurikuler.jpg` — hero ekstrakurikuler
- `hero-prestasi.jpg` — hero prestasi
- `hero-layanan.jpg` — hero layanan

## Gambar konten

Gambar yang berkaitan dengan prestasi atau galeri sebaiknya ditempatkan di folder `konten/galeri/` atau `konten/prestasi/`, bukan di folder ini.

## Catatan

Untuk saat ini file gambar hero belum diunggah. Setelah desain final disepakati, upload gambar dengan nama yang sesuai agar halaman otomatis menemukannya.
