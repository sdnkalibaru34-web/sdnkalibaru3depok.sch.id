# Data Website

Folder ini berisi data yang dibaca oleh website.

## File

- `sekolah.json` — identitas, statistik, kontak, dan informasi umum sekolah.
- `pengumuman.json` — daftar pengumuman.
- `agenda.json` — daftar agenda dan kegiatan.
- `prestasi.json` — daftar prestasi.
- `layanan.json` — daftar layanan digital.

## Aturan sederhana

- Jangan mengubah nama file JSON.
- Jangan menghapus tanda `{}`, `[]`, tanda kutip, atau koma secara sembarangan.
- Untuk sementara, item dengan `status: "draft"` tidak akan ditampilkan pada halaman publik ketika sistem daftar konten sudah dipasang.
- URL dapat dikosongkan (`""`) jika belum tersedia.

Struktur ini sengaja dibuat agar pembaruan konten dapat dilakukan tanpa mengubah HTML halaman.
